# 我哋呢班打工仔～ Not A Slave!

Vite + React + Tailwind. Zero backend: all data stays in the browser's localStorage.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build -> dist/
```

Deploy on Vercel: import the repo, framework preset "Vite", no extra config
(routing uses HashRouter, so no rewrites are needed).
